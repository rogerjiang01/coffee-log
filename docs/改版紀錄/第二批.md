## 實際做法和計畫不同的地方

| 計畫 | 實際 | 理由 |
|---|---|---|
| 未選的強度圓點與星等維持空心（計畫的建議） | 實心的 `--control-inactive` | 使用者的決定（上表第 3 項） |
| 卡片裡的表單列照 Figma，左右內距 24px | 16px | Figma 的卡片寬 380、幾乎貼齊 390 的螢幕；現在的頁面邊距是 20px，再留 24px 的話內容只剩 302px。這是頁面結構，第三批一起改 |
| 器材選擇器的新增畫面屬於「浮層裡的就地新增」，用有框的 input | 用表單的列（卡片） | 那個畫面是一張完整的表單（型號下拉、名稱、備註、常用），而下拉沒有「有框」的設計；和器材表單同一套才一致。有框的 input 實際用在：登入、註冊、下拉面板的搜尋、豆子下拉裡的就地新增、新增風味詞 |
| 值太長時「最多兩行、超過省略」 | 文字輸入只在**沒在輸入時**這樣顯示；輸入時是一般的單行輸入框 | 正在改的字不能被省略掉。做法是 `SheetText.vue`：顯示用的一層和 `<input>` 疊在同一格。原生的 `select` 與日期只有一行，放不下時省略 |
| 日期的膠囊和其他值一樣 18px | 16px，月曆圖示攤成透明蓋住整個膠囊 | `2026/11/13 下午04:56` 加月曆圖示，18px 在 375px 的列裡放不下，會被切掉 |
| 下拉沿用原本的 ⌄ | 拿掉了（下拉與器材欄位的 ›、⌄ 共 6 個） | 照 Figma 的 Sheet Row：膠囊本身就是線索。收合區的 ⌄ 還在 |
| 收藏維持愛心的開關 | 改成一般的開關，自己一張卡片，「還想再沖一次」在卡片下方 | 照 Figma 的記錄表單；計畫裡寫的是「三處開關統一」。紀錄詳情與列表的收藏愛心沒有動 |
| 總覽卡片這批只補陰影 | 照做；另外器材列表的卡片、比較表、照片欄位也補了 `--shadow-light` | 《03》§2.3：卡片底色和頁面底色只差 1.02:1，靠陰影分層 |
| 裁切介面的按鈕換成 `AppButton` | 沒有換 | 它在深色媒體面（`--media-bg`）上，用的是 `--media-border` 與 `--on-media`；換成綠框綠字會讀不到 |
| 登入、註冊的錯誤訊息維持在按鈕上方 | 「尚未填寫」「至少 6 個字元」改顯示在那一格下方（框變成錯誤狀態）；帳密錯誤、連線錯誤仍在按鈕上方 | 有框的輸入框有錯誤狀態，要有地方用到它；文案沒有改 |
| 有框輸入框的必填 `*` | 做成 `required`，沒有地方用 | 三個必填欄位都在表單的列裡 |
| 咖啡豆插畫用在「沒有照片時的縮圖」 | 只有縮圖（總覽、結算頁、豆子列表）用了；豆子詳情的大色塊（上面疊豆名）沒有 | 待辦寫的是縮圖；大色塊上疊著豆名，加插畫會干擾。第三批再看 |

## 做的時候才發現的事

- **比較表收藏列的日期連結是 `--accent` 在 `--accent-wash` 上，只有 4.18:1**（§2.2 早就寫了不可以）。
  改成收藏列用 `--on-accent-wash`（7.38:1）。
- **`--text-muted` 疊在 `--accent-wash` 上的地方實際只有一處**：器材選擇器已選的那一列（「昨天用過」「常用」）。
  其餘 13 個同時出現兩個 token 的檔案，兩者並沒有疊在一起。
- **星等的明度對比是 3.42:1**（`--favorite` 對 `--control-inactive`），圓點才是 3.88:1。兩者都寫進《03》§2.2。
- **綠底上有框輸入框的聚焦與錯誤幾乎一樣**：聚焦是 sand-100 的框、錯誤是 coral-50 的框，在綠底上都是淺色，
  只靠下方的錯誤訊息區分。沒有處理（那是綠底模式的 token 值），第三批重做登入頁時要決定。
- **測試是用正則比對原始碼的**，元件一改寫就要跟著改：這批動了 `icon-stroke`、`dialog-title`、`css`、
  `navigation-wiring`、`portal`、`photo-cropper`、`share-wiring`、`glossary`、`step-times-toggle`、
  `interaction-time-wiring`、`sample-badge-wiring`。斷言的意思都保留，只換比對的寫法；
  `icon-stroke` 多了「圓點、星等、開關用 `--control-inactive`、可點範圍 44px」的檢查。
- **必填的列不能用 `FormRow` 的 `label`**：`required-placeholder.test.mjs` 靠 `<label for>…<span class="sr-only">必填</span>`
  找必填欄位，所以必填的列自己寫標籤。
- **`TextField` 的 `class` 要留在最外層**：一開始 `inheritAttrs: false` 把 `class` 也交給了 `<input>`，頁面排的間距因此沒有作用。
- **兩行省略不能寫在有內距的那一層**：被切掉的第三行會從下方的內距露出來。膠囊與列內文字都是兩層。
- **`text-xs` 從 41 處剩 6 處**（`BrewTimelineItem`、`SharedBrewView`、兩個詳情頁、`app.vue`、`error.vue`），
  都在這批沒有碰的地方。
- **驗證用的假資料**：不登入看登入後的頁面，用的是暫時的 `plugins/zz-dev-fake.client.ts`（假 session、攔下所有送往 Supabase 的請求）
  與 `redirectOptions.exclude: ['/*']`，截完圖已經刪除、還原，沒有進任何 commit。
