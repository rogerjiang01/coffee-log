# 04 詞彙表

新增或修改任何面向使用者的文案前，先查這份表。

**收錄範圍**：出現在介面文案或規格（《01》《02》《03》）裡的咖啡領域與產品用詞。沒有出現在任何欄位或文案裡的詞不收，這不是咖啡百科。

**第三欄最重要。** 那些同義詞每一個都「也通」，所以最容易被人順手改回去。改回去之後，同一個概念在畫面上有兩種叫法，使用者會以為那是兩件事——這個產品已經因此混淆過一次（「沖煮時間」曾同時指兩件事）。要改用詞，先改這份表，再改介面。

`tests/unit/glossary.test.mjs` 會掃介面文案，第三欄的詞出現就失敗。

## 長短版的使用規則

有些詞有全稱與簡稱：研磨刻度／刻度、沖煮手法／手法、養豆天數／養豆。這不是混亂，是版面限制。

- **欄位標籤與內文用全稱**
- **表格欄位標題空間不夠時才用簡稱**（比較表的「刻度」「養豆」）
- **同一個層級不混用**：同一張表的欄位標題、同一個表單的欄位標籤，要嘛都全稱、要嘛都簡稱

簡稱只能是全稱去掉前綴，不能換成另一個詞。「刻度」可以，「研磨度」不行。

## 一、時間

| 使用的詞 | 精確指什麼 | 刻意不用的同義詞及原因 |
|---|---|---|
| **沖煮日期** | 這一杯是哪一天、幾點沖的（`brews.brewed_at`，含時刻） | **沖煮時間**：這個詞給了 `total_time`，兩件事不能共用一個名字。**紀錄時間／建立時間**：那是資料寫入的時刻（`created_at`），事後補記時兩者不同 |
| **沖煮時間** | 這一杯沖了多久，分:秒（`brews.total_time`）。從哪裡算到哪裡由使用者自己決定，規格不定義 | **總沖煮時間**：以前為了和「沖煮時間」（當時指日期）區分才加「總」，現在沒有「非總」的沖煮時間了。**總時間**：不知道是什麼的總和。**萃取時間**：萃取是咖啡粉接觸水的化學過程，會讓人聯想到萃取率。**時間**（單獨出現）：分不出是沖煮時間還是停水時間；比較表曾經這樣寫，已改掉 |
| **停水時間** | 注完一注到下一注開始之間的秒數，不含注水動作本身（`brew_steps.hold_seconds`、模板的 `duration`）。最後一段沒有下一注，沒有停水時間 | **停水時長／停水秒數／純停水**：同一件事的三種說法，多一個詞就多一個「這兩個是不是不一樣」的疑問。「純」是當初為了和舊定義（含注水動作）區分才加的，舊定義已經移除。**斷水時間**：「斷水」字面強調把水流切斷的那一下，不是之後等待的那段；同一個產品出現兩個詞，會被當成兩件事。**停留秒數／停留時間**：「停留」只當欄位標籤用，見下一列。**等待時間**：`step_type` 另有 `wait`，是另一種段落 |
| **停留** | **只當欄位標籤**：分段每一段的第二個輸入格「停留 ___ 秒」，填的是停水時間 | 標籤不改成「停水時間」：「停留」是咖啡圈的通用說法，而且短，放得進窄欄。但**除了這個標籤以外一律用「停水時間」**，說明文字、切換入口、差異區都一樣 |

## 二、水與粉

| 使用的詞 | 精確指什麼 | 刻意不用的同義詞及原因 |
|---|---|---|
| **粉重** | 這一杯用了幾克咖啡粉（`brews.dose`，g）。必填 | **粉量**：「量」可以是體積，手沖記的是重量。**豆量／豆重**：研磨前後重量相同，但這個欄位記的是放進濾杯的東西。**劑量**：翻譯腔 |
| **注到** | **只當欄位標籤**：分段每一段的第一個輸入格「注到 ___ g」，填的是累積水量 | 標籤用動作的語言，因為使用者填的時候眼睛看著磅秤、手在注水。這個值在其他地方一律叫「累積水量」 |
| **累積水量** | 這一段注完時磅秤上的數字（`brew_steps.cumulative_water`）。例：40 → 160 → 220 | **水量**（單獨出現）：分不出是這一段注了多少、還是注到多少。**累計水量**：同義，只留一個。**注水量**：容易讀成「這一注注了多少」，那是增量，不是累積值。差異區的標籤是「各段累積水量」，不是「各段水量」 |
| **增量水量** | 這一段本身注了多少，＝這段的累積水量 − 前一段的累積水量。衍生值，不存資料庫。介面上以「+120g」呈現 | **注水量**：同上，太容易和累積水量混淆，所以規格裡一律寫「增量水量」 |
| **總水量** | 最後一段的累積水量。衍生值，不存資料庫 | **總注水量**：多一個字不多資訊。**用水量**：聽起來包含溫杯、潤濕濾紙的水 |
| **粉水比** | 總水量 ÷ 粉重，顯示為「1:15.0」。衍生值；手法的 `default_ratio` 也是這個比值 | **水粉比**：順序反過來，會讓人懷疑分子分母是不是也反了。**比例**（單獨出現）：《02》比較表的示意圖曾寫「比例」，不知道是什麼的比例 |
| **水溫** | 注水時的水溫（`brews.water_temp`，°C） | — |

## 三、分段

| 使用的詞 | 精確指什麼 | 刻意不用的同義詞及原因 |
|---|---|---|
| **分段注水** | 一筆紀錄裡依序的每一注（`brew_steps`）。表單上那一區的標題 | **注水段**：沒有人這樣說。紀錄詳情頁的標題簡稱「分段」，那是同一個東西 |
| **段**、**第 N 段** | 分段注水裡的一筆。段號從悶蒸之後的第一個一般段落數起，沒有悶蒸時第一段就是「第 1 段」 | **段落**：只用在「段落備註」這個固定說法裡，其他地方用「段」。**第 N 注**：「注」是動作，「段」是紀錄的單位；模板的備註裡會出現「第一注」，那是在描述動作本身 |
| **注水** | 把水倒進濾杯的動作 | **給水**：規格裡曾經用過，和注水同義，只留一個。**沖水**：口語，不精確 |
| **悶蒸** | 第一段用少量水（通常是粉重的 2 到 3 倍）讓粉床濕透、排出二氧化碳（`step_type = 'bloom'`）。水量依粉重決定（`dose` 基準） | **預浸**：浸泡式沖煮的說法。**悶粉／開花**：口語，不統一。**四六法的第一注不是悶蒸**，不能叫悶蒸，資料上是 `pour` |
| **攪拌** | 這一段有用攪拌棒或湯匙攪動粉層（`step_type = 'stir'`），是一個標記，不注水 | **攪動**：同義，只留一個 |
| **搖晃（濾杯）** | 注完之後拿起濾杯旋轉搖晃，讓粉床平整。只出現在手法模板的備註與說明裡 | **晃動**：同義，只留一個。使用者既有紀錄的段落備註裡可能還有「晃動」（當初從模板帶入後存下來的），那是紀錄，不改。**「輕晃」不在此列**：它描述的是力道（五段式最後一段「輕晃濾杯」），不是搖晃的同義詞，保留 |
| **段落備註** | 某一段的自由文字（`brew_steps.note`） | — |

## 四、研磨

| 使用的詞 | 精確指什麼 | 刻意不用的同義詞及原因 |
|---|---|---|
| **研磨刻度** | 磨豆機面板上的讀數（`brews.grind_setting`）。簡稱「刻度」，只用在比較表欄位、時間軸這類空間不夠的地方，以及刻度規格那一行（「刻度 1–8」） | **研磨度**：指的是粉的粗細本身，那是結果；不同磨豆機的同一個刻度，粗細完全不同，這個欄位記的是讀數不是粗細。**粗細**：同理。**格數**：「格」只出現在型錄備註（「一圈 40 格」），描述面板構造 |
| **刻度範圍** | 型錄記載的面板最小到最大值（`grind_scale_min`／`max`） | — |
| **最小間隔** | 面板能停的最小一步（`grind_scale_increment`），例如 0.5、1 | **級距／步進**：工程用語 |
| **連續無段** | 面板沒有段落、可以停在任何位置（`increment` 為 null） | **無段**：型錄備註裡會出現，意思相同；介面的固定說明寫全「連續無段」 |
| **手沖常用** | 型錄記載的手沖實用範圍（`grind_scale_suggested_min`／`max`） | **建議範圍**：「建議」聽起來像系統替使用者決定 |

## 五、手法

| 使用的詞 | 精確指什麼 | 刻意不用的同義詞及原因 |
|---|---|---|
| **沖煮手法** | 一套分段注水的做法（`brew_methods`），選了會依粉重帶入分段。簡稱「手法」，用在空間不夠的地方 | **沖法**：只剩手法的別名裡還有，名稱裡已經拿掉。**沖煮法／沖煮方式**：同義，只留一個。**手沖手法**：這個產品只記手沖，「手沖」不承載資訊。**注水手法**：那是另一件事，見下一列 |
| **注水手法** | 注水時的繞圈方向、半徑、水柱大小、速度。只有 `brew_steps.pour_pattern`（中心、繞圈、螺旋）建了欄位，其餘三項不建；第一版介面都不露出 | 不能簡稱「手法」：會和沖煮手法混在一起 |
| **分段模板** | 手法裡記載每一段怎麼分水、停多久的比例資料（`brew_methods.step_template`） | **模板**單獨出現時要確定上下文是手法 |
| **手法名稱** | 三段式、四六法、五段式 Rao Spin、Perger 攪拌流、肥尾法 | 不帶「沖法」：選單的脈絡已經說明那是手法，每個名稱都重複一次只是雜訊。舊名稱（三段式沖法等）留在 `aliases` 供比對 |

## 六、豆子

| 使用的詞 | 精確指什麼 | 刻意不用的同義詞及原因 |
|---|---|---|
| **豆子**；量詞「**支**」 | 一包咖啡豆（`beans`）。「這支豆子」 | **咖啡豆**：可以，但導覽與標題用「豆子」。量詞不用「**隻**」（那是動物的量詞）、「款」「包」：介面上一律「支」 |
| **烘焙日期** | 豆袋上的烘焙日（`beans.roast_date`） | — |
| **養豆天數** | 沖煮日期 − 烘焙日期。衍生值，不存資料庫。卡片與比較表空間不夠時寫「養豆 N 天」「養豆」 | **養豆期**：指建議等待的區間（例如「養豆期 7–14 天」），不是已經過了幾天。**熟成天數**：少見。**賞味期**：是另一件事 |
| **烘焙度** | 淺焙、中淺焙、中焙、中深焙、深焙（`beans.roast_level`） | **焙度／烘焙程度**：同義，只留一個。選項一律用「X焙」，不寫「淺烘焙」 |
| **處理法** | 水洗、日曬、蜜處理等（`processing_methods`） | **處理方式／後製**：同義，只留一個 |
| **品種**、**產國**、**產區** | `varieties`、`countries`、`beans.region` | **產地**：分不出是國家還是產區 |
| **咖啡店名** | 豆子從哪裡買的、誰烘的（`beans.roaster`） | **烘豆商／烘焙商**：使用者多半是在店裡買的，記得的是店名 |
| **官方風味描述** | 豆袋或店家寫的風味（`beans.official_notes`） | **風味筆記**：會和使用者自己的「心得筆記」混淆 |

## 八、紀錄與品飲

| 使用的詞 | 精確指什麼 | 刻意不用的同義詞及原因 |
|---|---|---|
| **照這次再沖一次**／**照上次再沖一次** | 複製一筆紀錄的參數與分段，開一張新表單。紀錄詳情頁寫「這次」，豆子詳情頁寫「上次」（永遠是最新那筆） | 按鈕不寫「複製紀錄」：使用者要的不是複製一份資料，是再沖一杯。規格裡這個流程叫「複製」 |
| **收藏** | 「還想再沖一次」的標記（`brews.is_favorite`），以愛心圖示表示 | **最愛／喜歡**：同義，只留一個。規格裡的「愛心」指的是圖示 |
| **評分**、**強度**（酸質、甜感、醇厚、苦味）、**風味標籤**、**心得筆記** | 品飲欄位。規格裡這一組統稱「品飲」 | 強度不是好壞：說明文字寫「描述強弱，不是好壞」 |
| **差異**、**相對上一次** | 這筆與複製來源不同的地方（衍生值） | — |
| **帶入** | 把既有的值填進表單：複製來源的參數、手法的分段模板、常用器材、按鈕下方的「帶入 3/12 那次的參數」 | **代入**：數學用語（代入公式），而且同一個動作兩種寫法會被當成兩件事 |
| **暫存**（暫存中、已暫存） | 表單內容自動存在這台裝置上的草稿（localStorage），還沒進資料庫 | **儲存**：那是按鈕的動作，寫進資料庫。狀態指示寫「已儲存」會讓人以為已經存好了，不必再按 |
| **儲存** | 按下按鈕，寫進資料庫 | **送出**：表單不是寄給誰。**保存**：同義，只留一個 |

## 九、導覽與動作

三個詞以前混在一起：同一個「取消」在表單頁右上角其實保留暫存、在器材表單真的丟棄、在就地新增是清空輸入。判斷的依據只有一條——**按下去會不會丟東西**（《03》§3）。

| 使用的詞 | 精確指什麼 | 刻意不用的同義詞及原因 |
|---|---|---|
| **返回** | 檢視型畫面左上角的 ‹：回到內容階層的上一層（紀錄 → 它的豆子 → 豆子列表）。不丟任何東西。只當圖示的無障礙名稱，畫面上不寫字 | **回豆子列表、回首頁**（文字連結）：返回的方向由階層決定，用圖示表達；寫成文字又放在頂部，會跟頁面動作混在一起。「回首頁」只留在錯誤頁——那裡沒有分頁列，它是唯一的出口 |
| **離開** | 流程型畫面（表單）左上角的 ‹：離開這個流程，**暫存留著**，回來還在。只當圖示的無障礙名稱 | **取消**：以前表單頁右上角寫「取消」，實際上什麼都沒丟，使用者卻以為按了就沒了。**返回**：同一個圖示，但「離開」提醒這裡是一個還沒完成的流程 |
| **取消** | **會丟東西**的放棄：清掉就地新增填到一半的內容、不保留裁切中的照片、不執行刪除。一律用文字，不用圖示 | **離開、返回**：那兩個不丟東西。**關閉**：只用在 × 圖示，表示收起一個不會丟東西的浮層。「取消常用」是另一件事（把這台從常用拿掉），不在此列 |
| **重試** | 讀取失敗時再讀一次：錯誤頁、頁內的錯誤邊界、詳情頁與編輯頁的讀取失敗，全部同一個詞 | **重新載入**：以前錯誤頁用這個，頁內用另一個，同一個動作兩種叫法。**重試這一頁**：「這一頁」不承載資訊 |
